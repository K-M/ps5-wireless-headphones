PS5 Wireless Headphones — Flasher

Flash both boards from Chrome or Edge on a computer. No tools to install.

Both boards must use the same channel. Pick the one with the fewest Wi-Fi networks near you; if you hear dropouts, try another.

1. Transmitter (plugs into the PS5)

  1. Hold the board's BOOT button while plugging it into this computer, then release.
  2. Click below and pick the new serial port.
Use Chrome or Edge on a desktop. This page must be opened over HTTPS.

2. Receiver (drives the USB headphone dongle)

  1. Enter download mode: bridge the B1 pad/pin to GND and tap RESET (Waveshare ESP32-S3-Nano has no BOOT button), then remove the bridge after flashing.
  2. Click below and pick the serial port.
Use Chrome or Edge on a desktop. This page must be opened over HTTPS.

After flashing, unplug and re-plug each board (or tap RESET). Source and wiring: see the repository README.
